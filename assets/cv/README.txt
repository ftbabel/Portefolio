Dossier réservé à votre CV au format PDF.

Pour activer le téléchargement direct depuis le bouton « Télécharger mon CV » :
1. Déposez votre fichier PDF dans ce dossier (ex. : CV_Fatou_Thiam_UX_UI.pdf).
2. Ouvrez `script.js` et renseignez le champ `cvFile` dans `PORTFOLIO_CONFIG` :
   cvFile: "./assets/cv/CV_Fatou_Thiam_UX_UI.pdf"
   cvReady: true
